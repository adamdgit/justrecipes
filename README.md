# Easy Recipes

A web application that transforms YouTube cooking videos into beautifully formatted recipes. Using the GPT Assistant API, the app extracts measurements, ingredients, and instructions, embedding the video alongside the generated recipe for a seamless user experience.

## Purpose
The Recipe Generation App simplifies cooking by turning YouTube video instructions into clear, easy-to-follow recipes. With features to save, rate, and search recipes, it provides a personalized and accessible way to discover new dishes.

### Features
- Recipe Generation: Create recipes by pasting a YouTube video URL.
- Embedded Videos: Watch the original video next to the generated recipe.
- Save Recipes: Keep track of your favorite recipes.
- Rate Recipes: Provide feedback by rating recipes.
- Search Recipes: Browse through the recipe database with a built-in search functionality

#### Usage
Create an Account: Sign up and log in to access the app's core functionality.
Generate Recipes: Logged-in users can create recipes by providing a YouTube video URL.
Browse Recipes: Search through the database of recipes, even without logging in.
Save and Rate: Logged-in users can save their favorite recipes and provide ratings.
